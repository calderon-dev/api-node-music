# 🎵 API RESTful con Node.js, Express y MongoDB

Este proyecto implementa una **API RESTful completa** utilizando **Node.js**, **Express** y **MongoDB** con **Mongoose**.  
Incluye autenticación con JWT, paginación avanzada con `mongoose-paginate-v2`, validaciones y buenas prácticas de arquitectura.

---

## 🚀 Características principales
- CRUD completo para entidades (ej. artistas, usuarios).
- Autenticación y autorización con **JWT**.
- Paginación eficiente con **mongoose-paginate-v2**.
- Validaciones de entrada y manejo de errores.
- Arquitectura modular (controladores, rutas, middlewares).
- Preparado para despliegue en producción.
